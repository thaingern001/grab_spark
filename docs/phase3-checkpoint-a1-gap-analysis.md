# Checkpoint A.1 visual gap analysis

The comparison uses the six 390 × 844 baseline captures in `screenshots/checkpoint-a1/before/`, the seven images supplied with the request, and Grab's public merchant guides. These references vary by market and app version; this concept does not claim pixel fidelity.

| Area | Current prototype | Reference pattern | Revision |
| --- | --- | --- | --- |
| Header | Large GrabMerchant wordmark and repeated “concept” strapline | Store context leads the home view; secondary account affordance | Compact Westrong Kitchen identity with a small persistent unofficial label |
| Home | Sales and AI occupy large cards; operations are long rows below | Today's highlights and a dense shortcut grid | Put store context, quick tasks, summary, and One Click within the first scroll |
| Orders | Oversized single count and explanatory card | Task title, tabs, compact order information | Show honest completed-history summary and trend without implying live fulfillment |
| Menu | Large disclaimer before plain rows | Clear category sections, item names/prices, availability | Compact grouped rows and quiet data provenance |
| Insights | Generic KPI dashboard | Period tabs, sales trend, menu performance | Compact measures and a chart with true backend values and labels |
| AI | Introductory marketing card before the mission | Merchant action within the operational app | Direct Opportunities and Mission Activity views |
| Review/tracking | Four steps inside generic cards | Decision-first mobile layout | Put comparison and assumptions near the decision, retain edit, revision, approval, and simulation safeguards |

Official references: [GrabMerchant Handbook](https://hodor-assets.grab.com/attachments/merchant/en-ph/articles/22150/rc-upload-1714107664018-2-GrabMerchant%20Handbook.pdf), [Managing Insights](https://hodor-assets.grab.com/attachments/merchant/en-sg/articles/3409/rc-upload-1724146183913-3-Mex%20Deployment%20Guide%20%28Aug%202024%29.pdf), [GrabMerchant Insights Help](https://help.grab.com/merchant/en-my/4414717693209), and [New GrabMerchant Home](https://merchant.grab.com/en-ph/blog/welcome-to-the-new-grabmerchant-home).

The supplied screenshots informed the layout, spacing, density, navigation rhythm, and green emphasis. No screenshot, logo artwork, or other proprietary asset is copied into the UI.
